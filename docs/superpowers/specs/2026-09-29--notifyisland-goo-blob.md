# NotifyIsland 1.12.3 — goo-шарик буфера (World of Goo)

Дата: 2026-09-29
Статус: реализуется
Заменяет: 1.12.2 «деление пилюли надвое»

## Проблема

1.12.2 делит капсулу надвое: слева остров с часами, справа прямоугольная половина с превью
буфера. Пользователь требует исходную концепцию World of Goo — буфер **отделяется в
отдельный круглый шарик**, соединённый с капсулой тонким мостиком, шарик перетаскивается
мышью, а по клику разворачивает историю буфера.

## Зафиксированные решения (ответы пользователя)

| Вопрос | Решение |
|---|---|
| Содержимое шарика | Иконка файла/буфера + короткий текст, как сейчас в половине |
| Связь с островом | Тонкий мостик, **всегда неразрывный**; шарик перемещается, остров статичен; перемещение ограничено ~50–100 px |
| После отделения | Покачивается; клик по шарику разворачивает список истории буфера |

## Геометрия

Все числа — константы `OverlayTokens` (DIP), геометрия — чистые функции в
`NotifyIsland.Core/ClipboardBlob.cs` (тестируются без UI).

- `BlobD = 64` — диаметр шарика.
- `BlobBridgeMin = 18` — минимальная длина мостика у домашней позиции.
- `BlobBridgeBaseHalf = 12` — полуширина мостика у капсулы.
- `BlobBridgeTipHalf = 5` — полуширина мостика у шарика.
- `BlobDragMaxPx = 100` — предел смещения шарика от домашней позиции.

### Окно

Сейчас размер окна == размер капсулы (`SetSizeImmediate` ставит `Pill.Width = Width`).
С шариком это уже не так: окно должно вмещать капсулу, мостик, шарик **и всё поле
перетаскивания**, иначе шарик обрежется краем окна.

Горизонтальный остров (Top/Bottom), split:

```
W = homeW + BlobBridgeMin + BlobD + BlobDragMaxPx
H = homeH + 2 * BlobDragMaxPx
```

Вертикальный остров (Left/Right) — те же два числа, но длинная ось это Y:

```
H = homeH + BlobBridgeMin + BlobD + BlobDragMaxPx
W = homeW + 2 * BlobDragMaxPx
```

**Остров не смещается.** Окно достраивается в сторону шарика (по длинной оси) и симметрично
по короткой, а капсула внутри окна прижата к «дому»:

- горизонталь: `X = homeX`, `Y = homeY - (H - homeH) / 2`, капсула `Left` + `Center` по Y;
- вертикальный: `Y = homeY`, `X = homeX - (W - homeW) / 2`, капсула `Top` + `Center` по X.

`homeW/homeX/homeY` — размер и позиция, которые дал бы `IslandLayout` без blob. Это
единственное место, где окно и капсула расходятся, поэтому вся остальная логика
(морф, зоны клика, hit-test острова) продолжает работать по `homeW`.

### Позиция шарика

Домашняя позиция — по длинной оси сразу за капсулой, по короткой — напротив центра
капсулы. Смещение от дома clamp'ится **по кругу** радиуса `BlobDragMaxPx` (не по квадрату):
квадрат дал бы диагональ 141 px, круг — ровно 100 во всех направлениях, включая
вверх-вниз, где окно и было расширено.

Мостик строится **между центром шарика и ближней точкой капсулы** при каждом кадре
перетаскивания. Так неразрывность не «обещается анимацией», а обеспечена структурно:
конец мостика — это центр шарика, начало — край капсулы, разрыв невозможен по построению.

## Анимация

Отделение едет по существующему морф-таймеру окна (тот же, что сейчас гоняет ширину
170 → 370), поэтому новой анимационной инфраструктуры не нужно:

- шарик стартует в центре капсулы и выезжает на домашнюю позицию по кривой ClickPop
  (1.0 → 1.06 → 1.0), задержка появления = `ClipboardHalfFadeDelay` от старта морфа;
- мостик растёт вместе с ним: до 25 % морфа шарик невидим, мостик прижат к капсуле;
- после отделения — breathe ±0.5 DIP по короткой оси, период `ClipboardHalfBreatheMs`;
- при исчезновении шарика мостик втягивается в капсулу тем же морфом.

## Ввод

- `PointerPressed` по шарику → начало drag, захват указателя.
- `PointerMoved` → смещение = clamp(круг `BlobDragMaxPx`), перестроение мостика.
- `PointerReleased` → если смещение ≤ `OverlayTokens.ClickMaxPx`, это клик: развернуть
  историю буфера. Иначе — отпустить шарику в текущей позиции.

Порог тот же, что у капсулы, поэтому «перетащил» и «кликнул» не путаются.

**Кликабельность:** прозрачное окно теперь намного больше капсулы и перехватило бы
клики по рабочему столу. Поэтому `IsHitTestVisible = False` на контейнерах и `True`
только на капсуле и шарике. Мостик не кликабелен (тянется за шариком, а не за собой).

## Панель истории (клик по шарику)

Отдельный UI, которого в проекте нет: сейчас история живёт только как цикл превью
‹/› внутри островка (`RefreshIdleClipboardCycle`). По клику разворачивается панель со
списком `_clipboardHistory.SnapshotNewestFirst()`: иконка + заголовок + «время назад»,
выбор элемента кладёт его в системный буфер.

## Что удаляется

`ClipboardHalf*` из `OverlayWindow.axaml` (разметка половины), `ClipboardSplit` как
источник геометрии окна (остаётся только расчёт зон клика острова), делитель.

## Проверка

Core-геометрия — тестами. Всё остальное — живым прогоном: лог + скриншоты на реальном
экране, потому что именно на живой проверке в 1.12.2 нашлись три бага, которых не видели
ни тесты, ни ревью.
