# NotifyIsland — превью фич (наш островок)

Список для утверждения. Простым языком, без сравнений с Apple/Xiaomi.
Правила реализации — в [`ISLAND_GUIDELINES.md`](ISLAND_GUIDELINES.md).

1. Плавающая капсула на Windows 11 — всегда на виду поверх рабочего стола (с настройкой слоя).
2. Три уровня показа: минимальный (часы), компактный с виджетом, расширенный с деталями.
3. Высота капсулы фиксированная — при уведомлении островок тянется только в длину, не вверх.
4. Плавный морф раскрытия и сворачивания за ~420 мс Soft easing (скорость настраивается; default Slow).
5. Мягкая подсветка при наведении курсора.
6. В свёрнутом виде: иконка часов и текущее время.
7. Светящаяся точка, если есть непрочитанные уведомления — мягко пульсирует, пока unread &gt; 0.
8. Короткий клик по свёрнутому островку открывает центр уведомлений Windows.
9. Правый клик — быстрое меню (демо, погода вкл/выкл, свернуть, настройки, выход).
10. Уведомление: иконка приложения, текст сообщения и бейдж с числом.
11. Уведомление само сворачивается примерно через 4 секунды, точка непрочитанных остаётся.
12. Режимы островокa: уведомление, прогресс, медиаплеер, таймер, ошибка, погода.
13. Свайп влево/вправо — переключение между виджетами (уведомления ↔ погода ↔ плеер ↔ часы).
14. Свайп вниз — свернуть в минимальный вид.
15. Свайп вверх — развернуть текущий виджет.
16. Если свайп недотянули — островок плавно откатывается назад.
17. Погода берётся из Windows (системные данные / кэш), без сторонних интернет-сервисов.
18. Минимальная погода рядом с часами: иконка условия и температура.
19. Расширенная погода: условие, температура и осадки подробнее.
20. Погоду можно полностью выключить.
21. В настройках выбирается, слева или справа от часов стоит погода.
22. Иконки погоды меняются под ясно / облачно / дождь / снег / грозу и т.д.
23. Смена иконки погоды с плавным переходом.
24. Единый outline-иконпак для часов, погоды, медиа, прогресса, трея — один стиль на светлой и тёмной теме.
25. Иконка в системном трее Windows (WinForms NotifyIcon; Avalonia TrayIcon — запасной вариант).
26. Левый клик по трею — показать/скрыть островок; правый — меню: настройки, островок, демо, погода, выход.
27. Двойной клик по трею — центр уведомлений.
28. В трее видно, что есть непрочитанные (точка на иконке).
29. Отдельное полноценное окно настроек с **боковой навигацией и иконками** (Островок / Погода / Расположение / Тема / Медиа и питание / Оформление / Анимации / Звуки / Иконки) — не попап и не меню трея; окно само запоминает размер и позицию.
30. Расположение островка: сверху, снизу, слева или справа.
31. Три режима слоя: поверх всех окон; на рабочем столе под окнами приложений; позади окон приложений.
32. ~~Перетаскивание мышью~~ — **убрано**; позиция только из настроек.
33. Точная позиция по пикселям (смещение X и Y + край экрана).
34. Ориентация: горизонтальная, вертикальная или авто под край экрана.
35. Показать или скрыть островок из трея/настроек.
36. Демо-режим для проверки анимаций (включается отдельно, не для повседневной работы).
37. Тёмная капсула с акцентным синим для бейджей и точки.
38. Шрифты и отступы выровнены «по пикселям», без кривой каши.
39. Островок не ворует фокус клавиатуры у других окон.
40. Настройки сохраняются между запусками.


41. Настраиваемая прозрачность фона капсулы — слайдер от непрозрачного до полупрозрачного, чтобы видеть рабочий стол.

42. Короткие тихие звуки на уведомление, раскрытие/сворачивание, свайп, ошибку и (опционально) hover — можно выключить и приглушить в настройках.

43. Окно настроек — отдельное полноценное окно с **sidebar + Lucide icons** (не TabControl, не длинный scroll-pile, не меню трея); позиция и размер запоминаются; повторное открытие активирует уже открытое.

44. Пакеты звуков в настройках: **Nothing** / **iOS** / **System** / **Off** — оригинальные короткие WAV (inspired by soft Glyph-like clicks и soft iOS-like taps, не официальные системные файлы Nothing/Apple); общая громкость и громкость по событиям.

44. Иконка в трее: левый клик — показать/скрыть островок; правый — меню (настройки, островок, демо, погода, выход); двойной клик — центр уведомлений; точка на иконке при непрочитанных.

45. В простое (часы) островок неподвижен — никакого «дыхания» или pulse (только при непрочитанных).

46. Скорость анимаций в настройках (**Анимации**): медленнее / обычная / быстрее / выкл — действует на морф и pulse.

47. Палитра в **Оформление**: заливка капсулы, акцент, текст основной/вторичный (persist + live Apply).

48. Пакет иконок (stub): IslandIcons + плановые Tabler/Lucide/Phosphor — см. `docs/ICON_PACKS.md`.

### Целевой стек (кратко)
Must: Now Playing, timer/progress alerts, compact↔expanded morph, top-center, fullscreen-safe, weather, tray, settings tabs, clicks only, clipboard history (text + paths), animation speed, palette, icon packs.
Backlog differentiators: file shelf / clipboard / launcher. Не копируем Apple TM naming; без fake Live Activities без Win API.


## 1.5.8 Анимации

- Стили появления: Inflate / SlideDown / FadeScale / Bounce / Pop
- Стили ухода: Collapse / SlideUp / FadeScaleOut / Ragged / Glitch
- Иконки масштабируются с FontSize (×1.0 / ×0.92)
- Demo циклирует стили; defaults: Bounce + Ragged, Slow

## 1.5.7 UX

- Размер шрифта 10–18 + семейство (System / Space Grotesk / JetBrains Mono)
- Палитра: свотчи + ColorPicker + превью
- Пакеты иконок Tabler (MIT) / Lucide (ISC) реально переключаются
- Вкладка «Анимации»: скорость по действиям + pulse toggle
- Nothing-inspired: только OFL-шрифты и soft clicks; без NType82 / Glyph firmware

## 1.12.1 — System Monitor (переделка)

48a. **Монитор — отдельная поверхность, а не строчка в часах.** В свёрнутом виде остаются только часы и дата; метрик в пилюле нет вообще. Монитор локальный, как и буфер обмена, без HTTP.
49. **Открытие по наведению**: наведение на пилюлю 250 мс открывает панель монитора, уход курсора закрывает её (с задержкой 500 мс, чтобы не мелькала). Настройка «Раскрывать при наведении» включает и выключает это. Автосворачивание по таймеру 30 с убрано.
50. **Клик в свёрнутом виде — только пин/анпин.** Раньше клик по строке метрик открывал монитор и тут же его закрывал; теперь метрики клик не перехватывают. Двойной клик по-прежнему открывает центр уведомлений. На пин/анпин добавлена анимация ClickPop.
51. **Четыре подписанные строки**: `CPU`, `Память`, `Батарея`, `Сеть` — подпись слева, значение справа, под ними полная дата (например, «вт, 28 сентября 2026»).
52. **Формат сети**: стрелки направления `↓` и `↑` и настоящие единицы `МБ/с` / `КБ/с` (переключение на 1024) вместо прежнего литерального `v`. Батарея помечается `⚡`, когда на питании от сети.
53. **Цвета по порогам**: обычно значение приглушённое (`#C8C8CC`); при переходе порога — синий `#3D9CF0` (CPU ≥ 70 %, RAM ≥ 85 %, батарея ≤ 20 %), при критическом — красный `#E8A0A0` (CPU ≥ 90 %, RAM ≥ 95 %, батарея ≤ 10 %).
54. **Размер**: панель 300 DIP в ширину; высота подстраивается под число выбранных строк (108 DIP у «Полностью», 48 DIP у «Кратко»).
55. **Свои строки и свой порядок.** В настройках можно выбрать, какие строки показывать, и переставить их местами кнопками ↑/↓. Три готовых варианта: **Полностью** (CPU, Память, Батарея, Сеть, дата), **Кратко** (только CPU и Батарея) и **Свой набор** — ручной выбор. Снятая строка не теряет своё место: включили обратно — вернулась там же.
56. **Живое превью в настройках.** Пока вы двигаете строки, рядом видно макет настоящей панели — те же настоящие строки и та же высота, что получится в пилюле. Если набор пустой, монитор просто не показывается.
57. **Быстрый вход**: правый клик по панели → «Настроить монитор…» открывает настройки сразу на разделе «Монитор». Полностью выключить монитор можно чекбоксом «Показывать системный монитор» — он же сохраняет ваш набор строк.
58. **Буфер обмена**: текст, файлы, многофайлы, счётчик. Не вставляется автоматически в чужое окно. С 1.12.2 показывается половиной островка — см. ниже.

Пример:

```
┌────────────────────────────────┐
│  CPU           12 %           │
│  Память        21,3 / 34 ГБ   │
│  Батарея       100 % ⚡        │
│  Сеть          ↓ 0,0 МБ/с ↑ 0 │
│  вт, 28 сентября 2026          │
└────────────────────────────────┘
```

## 1.12.2 — Буфер обмена делит островок пополам

59. **Копирование больше не занимает весь островок.** Раньше скопированный текст целиком занимал капсулу и часов было не видно. Теперь островок просто делится пополам: слева (или сверху) остаётся всё, что было — часы, дата, погода, батарея, точка непрочитанных, — а на другой стороне появляется вторая половина с тем, что вы скопировали.
60. **Одна капсула, а не две.** Обе половины — часть одной плавающей капсулы с общим скруглением; их разделяет тонкая вертикальная линия в 1 px, как разделитель в интерфейсе, а не рамка панели.
61. **Что видно в половине**: иконка формата (текст, файл или несколько файлов) и короткое превью. Текст обрезается до 22 символов с многоточием, переводы строк и лишние пробелы не ломают капсулу. Для файла — имя файла, для нескольких — «5 файлов» с правильным окончанием.
62. **Половина въезжает, а не появляется.** Она выезжает с дальнего конца, слегка проскальзывает мимо нужного места и встаёт на место — и проявляется чуть позже, чем растёт капсула, поэтому кажется одним движением, а не переключением. Пока вы не скопировали ничего нового, половина слегка покачивается (±0.5 DIP) — фоновое «живое», заметное только если присмотреться.
63. **Живёт 4 секунды** — столько же, сколько обычное уведомление, а не шесть, как было у прежнего буферного окна. Потом половина уезжает обратно тем же движением, капсула сворачивается в часы.
64. **Клик по этой половине закрывает её** и выполняет выбранное в настройках действие: по умолчанию — просто закрыть (вставить текст вы по-прежнему жмёте сами, Ctrl+V). Второй вариант в настройках — «закрыть и очистить буфер»: после клика в системном буфере обмена не остаётся ничего.
65. **На вертикальном краю экрана** (слева или справа) островок растёт вниз, а не вширь: вторая половина встаёт снизу, её текст повёрнут на 90° и читается вдоль длинной стороны. Высота островка при этом не меняется никогда.
66. Копирование по-прежнему **не** добавляет непрочитанных и **не** вставляет текст в чужие окна.

Пример:

```
┌───────────────┬────────────────────────┐
│  12:34  28 сб │ 📋 Скопирован текст…   │
└───────────────┴────────────────────────┘
   островок          скопированное
```
